# Creative Production and Quality Control SOP

**Status:** Proposed operating procedure.  
**Purpose:** Make each delivery traceable and consistent while keeping a human accountable for final output.

## 1. Workflow
1. **Intake:** Receive brief and source assets; assign project ID.
2. **Rights and risk check:** Review client permissions, AI-tool terms, third-party assets, likeness, trademarks, product claims, and platform constraints.
3. **Quote and approval:** Confirm scope, schedule, revisions, price, payment milestone, and license terms in writing.
4. **Creative direction:** Prepare concept, storyboard/moodboard, prompt plan, and sample direction.
5. **Checkpoint approval:** Obtain client approval before full production.
6. **Production:** Generate drafts using approved tools and authorized assets.
7. **Human finishing:** Edit, composite, correct, add captions/audio, and export.
8. **Internal QA:** Apply checklist; record tool/model/version and material human edits.
9. **Client review:** Share controlled preview; gather consolidated feedback.
10. **Revision:** Track each revision against agreed scope.
11. **Final approval and delivery:** Confirm approval, payment status, file list, and usage terms.
12. **Archive / deletion:** Retain only what contract and policy require; delete temporary material on schedule.

## 2. Quality checklist
### Visual integrity
- [ ] Correct subject, product, packaging, labels, and brand assets.
- [ ] No unintended extra/missing objects, malformed anatomy, or visual artifacts.
- [ ] No misleading product demonstration or unsupported before/after.
- [ ] Text, logo, spelling, and disclaimers checked manually.
- [ ] Consistent color, lighting, framing, and visual direction.

### Video integrity
- [ ] Motion and transitions are coherent.
- [ ] No flicker, temporal warping, or inconsistent subject details.
- [ ] Audio is clear and licensed for intended use.
- [ ] Captions are accurate and readable.
- [ ] Aspect ratio, duration, frame rate, and export settings match brief.

### Commercial and rights
- [ ] Third-party elements have documented licenses/permission.
- [ ] AI tool terms allow intended commercial use.
- [ ] Client approved factual claims and supplied materials.
- [ ] Final license matches quote/contract.
- [ ] No unapproved portfolio publication.

## 3. Version control
Use project ID + asset type + sequence + version, e.g. AVL-2026-0001-VIDEO-01-v03.mp4. Keep a change log with date, operator, tool/model, source assets, prompt/direction reference, human edits, reviewer, and approval state. Never store API keys or credentials in project notes.

## 4. Feedback rules
Ask for one consolidated feedback set from the authorized approver. Classify each item as included revision, new scope/change request, defect against approved brief, or subjective preference outside agreed direction. Quote extra work before proceeding. Correct AVORLUNE failures against the brief without mislabeling them as paid revisions.

## 5. Incident handling
Stop delivery for a rights complaint, privacy exposure, misleading output, unsafe content, or suspected unauthorized use. Preserve only necessary evidence, restrict access, notify the owner, and follow the incident/contract process.

## 6. Release gate
No file is final until QA passes, required approvals are recorded, payment conditions are met, and usage terms are attached.
