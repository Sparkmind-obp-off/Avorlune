# 04 — UX, Information Architecture & UI Direction

## Experience principles
- Premium and editorial, not a generic AI dashboard.
- Show the work and outcome before explaining the technology.
- Make the next action obvious.
- Keep the brief form guided and short; reveal advanced fields progressively.
- Keep project status and revision boundaries transparent.
- Mobile-first.

## Landing page narrative
1. Hero: outcome-led statement and one primary CTA.
2. Selected work: visual proof, with permission-cleared samples.
3. Services: image and video production.
4. Process: Brief → Direction → Production → Review → Delivery.
5. Why AVORLUNE: creative direction + AI-assisted speed + human quality control.
6. FAQ: process, inputs, revisions, rights and turnaround.
7. Final CTA: start a project.

## Visual system
- Direction: premium, modern, cinematic/editorial.
- Use a restrained neutral base with one controlled accent.
- Typography: expressive display face paired with highly readable sans-serif.
- Layout: generous whitespace, strong grids, image-led storytelling.
- Motion: subtle transitions only; respect reduced-motion preferences.
- Avoid: neon overload, robot imagery, excessive gradients, fake AI chat UI, dashboard-first marketing.

## Core form fields
Required: name, contact method, service category, project objective, short description, intended platform/use, desired format, deadline preference, consent to process submitted information.
Optional: brand/product URL, reference links, uploaded assets, visual references, budget range.

## Accessibility
Semantic headings, labels, focus states, keyboard operability, adequate contrast, alt text and reduced-motion support.
